Privacy Policy

Last updated: 17 November 2026

Youtube Factory is a private tool. Its only user is the owner of the YouTube channels it manages.

What data it uses

When the owner signs in with Google, the tool receives permission to upload videos to, and read statistics of, the owner's own YouTube channels. The sign-in token is stored only on the owner's own computer.

What it does with the data

It uploads and schedules the owner's videos and reads view counts for those videos. It does not collect, sell or share any data about anyone else, and it does not use Google user data for advertising.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
